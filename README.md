# 🎓 Smart Student Result Analyzer

A simple and user-friendly web application for managing and analyzing student examination results.

## 🚀 Features

- ➕ Add student details
- 📝 Enter subject-wise marks
- 🧮 Automatically calculate total marks
- 📊 Automatically calculate percentage
- 🏆 Automatic grade calculation
- 🔍 Search students by name or roll number
- 🗑️ Delete student records
- 💾 Data stored using browser Local Storage
- 📱 Mobile-friendly and responsive design

## 📈 Grade System

| Percentage | Grade |
|------------|-------|
| 90% – 100% | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | F |

## 💡 How It Works

1. Enter the student's roll number and name.
2. Enter marks for each subject.
3. Click **Add Student**.
4. The system automatically calculates:
   - Total marks
   - Percentage
   - Grade
5. Use the search box to find a student.
6. Student records can also be deleted.
